# 給与・待遇は「数字と条件のセット」で書く — 求職者が信頼する求人票の作り方

## はじめに

前回の記事では、仕事内容を「1日の流れ」で書くと求職者の応募が変わるという話をしました。

仕事のイメージがつかめたら、求職者が次に見るのは「給与と待遇」の欄です。

そして、
ここが求人票の中で最も「書き方」で損をしやすい場所でもあります。

「月給25万〜」。

建設業の求人票でよく見かける書き方です。
間違いではありません。でも、これだけでは求職者はほぼ反応しません。

理由は単純です。「25万円の上は何万円なのか」「25万円は手取りなのか額面なのか」「手当は別にあるのか」。疑問が残ったまま、次の求人にスクロールされてしまう。

この記事では、給与・待遇の数字を「正直に、しかし伝わる形で書く方法」をお伝えします。
数字を盛る必要はありません。今ある条件を、求職者が判断できる形に整えるだけです。

---

## 1. 「月給25万〜」で止まる求職者の頭の中

求職者が求人票の給与欄を見るとき、頭の中では3つの計算が走っています。

**「結局、自分はいくらもらえるのか」**

月給に幅がある場合、求職者は下限の数字を「自分の給料」として受け取ります。
「月給25万〜35万円」と書いてあっても、35万円を期待して応募する人はほとんどいません。

つまり、
下限の数字が「自分の条件に合うかどうか」の判断基準になります。

**「この数字に何が含まれているのか」**

月給30万円と書いてあっても、基本給が24万円で固定残業代が6万円なのか、基本給が30万円で残業代は別途なのかで、実質の待遇はまるで違います。

求職者は「月給の中身」が見えないと不安になります。
特に転職経験のある方ほど、「込み込みの数字」に警戒心を持っています。

**「この金額はどうやったら上がるのか」**

20代・30代の求職者にとって、入社時の月給だけでなく「3年後、5年後にいくらになるか」が応募の判断材料になります。

しかし、
昇給の条件が書かれていない求人票がほとんどです。

「昇給あり」の一言では、いつ、何をすれば、いくら上がるのかが分かりません。
条件が見えなければ、「上がらないのでは」と解釈されます。

---

## 2. 月給の書き方 — レンジと到達条件をセットにする

月給の書き方で応募率が変わるポイントは、「レンジ（幅）の両端」と「到達条件」を一緒に出すことです。

**よくある書き方と、改善した書き方を比べてみます。**

| 書き方 | 求職者の受け取り方 |
|--------|----------------|
| 月給25万円〜 | 上限が分からない。25万円固定だと思われやすい |
| 月給25万〜35万円 | 幅は分かるが「35万円は何年目？」と疑問が残る |
| 月給25万〜35万円（経験・資格を考慮） | 判断基準がある程度分かる |

3番目の書き方でも悪くありませんが、もう一歩踏み込むと反応が変わります。

```
月給 25万〜35万円
※経験・資格・前職給与を考慮して決定します
※未経験の方：月給25万円スタート（入社1年目の目安）
※モデル年収：入社3年目・2級施工管理技士取得で月給32万円
```

ポイントは3つです。

**レンジの下限と上限の両方を書く。**
下限だけだと「最低額しかもらえない」という印象になります。

**何で金額が変わるのかを明記する。**
「経験」「資格」「前職給与」など、判断基準を出してください。

**未経験者と経験者の目安を分けて書く。**
同じレンジに並べると、未経験者が上限に期待してしまい、面接でギャップが生まれます。

---

## 3. 手当は「ある」ではなく「いくら」で書く

建設業には業界特有の手当が多くあります。
資格手当、現場手当、皆勤手当、工具手当。これらは他業種にはない魅力です。

しかし、
求人票に「各種手当あり」としか書いていない会社が大半です。

「各種手当あり」は、求職者にとって情報ゼロです。
何が、いくらもらえるのかが分からなければ、ないのと同じに見えます。

**改善前：**
> 各種手当あり

**改善後：**
> - 資格手当（2級施工管理技士：月1万円 / 1級：月2万円）
> - 現場手当（遠方現場の場合：日額2,000円）
> - 皆勤手当（月1万円）
> - 通勤手当（月3万円まで実費支給）
> - 工具手当（自前工具を使用する場合：月5,000円）

手当の種類が少なくても問題ありません。通勤手当と資格手当の2つだけでも、金額を明記すれば「制度がしっかりしている会社だ」という印象になります。

特に資格手当は、「今は無資格だけど、資格を取れば収入が上がる」という将来像を見せられるので、未経験の求職者に効果があります。

---

## 4. 賞与・年間休日・社会保険 — 「あり」を「数字」に変える

給与以外の待遇欄も、同じ原則です。
「あり」を「数字」に置き換えるだけで、求職者の受け取り方が変わります。

### 賞与

| 弱い書き方 | 信頼される書き方 |
|----------|--------------|
| 賞与あり | 賞与 年2回（前年度実績：計3.0ヶ月分） |
| 業績による | 賞与 年2回（前年度実績：計2.5ヶ月分）※業績により変動あり |

実績がまだない場合は、正直に書いてください。

```
賞与 年2回（業績に応じて支給）※設立間もないため実績データなし
```

嘘をつくより、正直に書くほうが信頼されます。
実績が出たら更新すればいいだけです。

### 年間休日

「週休2日制」だけでは、実際に何日休めるのかが分かりません。

```
年間休日 110日
（日曜・祝日休み、土曜は会社カレンダーによる ※月1〜2回の土曜出勤あり）
GW・夏季・年末年始に長期休暇あり（各5〜7日）
```

建設業では土曜が現場次第というケースが多いですが、そのまま事実を書いてください。「完全週休2日」と書いて実態が違うほうが、入社後のトラブルになります。

注意点が1つ。年間休日に有給休暇を含めて日数を多く見せるケースがありますが、有給休暇は法定で別途付与されるものです。混ぜないでください。

### 社会保険

「社会保険完備」だけでも問題はありませんが、4つの保険名を書き出すだけで「本当にちゃんと入っている」という安心感が伝わります。

```
社会保険完備（健康保険・厚生年金・雇用保険・労災保険）
```

建設業では社会保険未加入の事業者もまだ一部存在するため、加入していること自体が差別化になります。

## 5. 数字を書くときの3つの鉄則

ここまでの内容を実践するとき、守ってほしいルールが3つあります。

**鉄則1：盛らない**

実態より良い数字で応募を集めても、面接で事実が分かれば辞退されます。
入社しても「聞いていた話と違う」で早期離職につながります。

控えめに書いて入社後に「思ったより良い」と感じてもらうほうが、結果的に定着率が上がります。

**鉄則2：曖昧にしない**

「各種手当あり」「休日は会社カレンダーによる」「給与は経験による」。
これらはすべて、求職者にとっては「情報がない」と同じです。

具体的な数字と条件を書けば書くほど、「この会社はちゃんとしている」という印象になります。

**鉄則3：数字と条件をセットにする**

「月給35万円」だけ見て応募した方が、面接で「それは10年経験者の場合です」と言われたら、不信感しか残りません。

数字には必ず「誰が」「どの条件で」その金額になるのかを添えてください。
数字と条件のセットが、信頼の基本単位です。

---

## まとめ：数字の「見せ方」を変えるだけで、応募の質が変わる

この記事でお伝えしたことをまとめます。

- 月給はレンジで書き、到達条件を添える
- 手当は「あり」でなく種類と金額を具体的に
- 賞与は回数と前年度実績をセットで
- 年間休日は日数と内訳を明記（有給を混ぜない）
- 社会保険は4つの保険名を書き出す

どれも、条件を良くする話ではありません。
今ある条件を、求職者が判断できる形に整える話です。

数字を正直に、具体的に、条件とセットで書く。
それだけで「この会社は情報をきちんと開示してくれる」という信頼が生まれ、応募の質が変わります。

## もっと詳しく知りたい方へ

この記事でお伝えした「数字と条件のセット」の書き方は、職種によって書くべき手当や訴求ポイントが異なります。

施工管理なら資格手当と昇給モデルを、重機オペレーターなら免許手当を、未経験向けなら入社1年目の月収例を。それぞれ押さえるべき数字が変わります。

私たちは、建設業の職種別に最適化した「そのまま使える」求人原稿テンプレート集を制作しました。

**「建設業 求人原稿テンプレート集」（20職種対応）**

- 施工管理・土木作業員・とび・鉄筋工・型枠大工・塗装・左官・電気工事士・重機オペ・解体工など現場系15職種＋事務管理系5職種
- 各テンプレートには「職種名の付け方」「仕事内容の1日の流れ」「給与・待遇欄の書き方」「NGチェックリスト」まで、空欄を埋めるだけで完成する構成
- 給与・手当・賞与・休日の「数字と条件セット」の記入例が全テンプレートに付属
- 一度購入すれば何度でも使い回し可能

**価格：980円（税込）**

求人原稿の代行は1職種1回で4,000円前後が相場です。このテンプレート集は20職種分を980円で、何度でもお使いいただけます。
