# 第7章　応募につなげるCTA・応募方法の書き方

---

## 最後の1行で応募を逃す

求人原稿を最後まで読んでくれた求職者は、すでに「この会社、ちょっといいかも」と思っています。しかし、原稿を最後まで読んだ人のうち、実際に応募ボタンを押す人は半分もいません。

残りの半分は「応募方法」の欄で止まります。応募ボタンの前で手が止まる理由は、主に3つです。

1. **「応募したら営業電話がかかってきそう」** という不安
2. **「まだ決めきれないのに、応募したら後戻りできない」** という躊躇
3. **「応募方法が面倒そう」** という億劫さ

この3つの壁を崩すのが、CTA（行動を促す文言）と応募方法の書き方です。

---

## CTA（行動を促す文言）の基本

### 「応募する」だけでは弱い

「ご応募はこちら」「応募する」というボタンは、求職者に「正式な応募」を連想させます。まだ迷っている段階の人は、「応募」という言葉の重さに怖気づいて離脱します。

**改善の方向**: 「応募」ではなく「軽い一歩」を促す言葉に変える。

| 弱いCTA | 改善したCTA |
|---------|-----------|
| ご応募はこちら | まずはお気軽にご連絡ください |
| エントリーする | まず話を聞いてみる |
| 応募フォーム | 5分で入力完了・職場見学だけでも歓迎 |
| 送信する | 1分で入力完了・お気軽にどうぞ |

### 「アクション＋安心材料」のセット

CTAは2つの要素をセットにすると効果的です。

```
【アクション】＋【安心材料】

例：
- 「まずはお気軽にご連絡ください」＋「職場見学だけでも歓迎です」
- 「お電話ください」＋「『求人を見た』とお伝えいただくだけで大丈夫です」
- 「Webから応募する」＋「入力は1分で完了します」
```

安心材料は、求職者の3つの不安に対応させてください。

| 不安 | 安心材料の例 |
|------|-----------|
| 営業電話の不安 | 「お電話差し上げません。こちらからの連絡はメール（またはLINE）のみです」 |
| 後戻りできない不安 | 「相談だけでもOKです」「見学だけでも歓迎です」「辞退も気兼ねなくどうぞ」 |
| 面倒くさい不安 | 「入力は1分で完了します」「履歴書不要」「電話1本でOK」 |

## 応募方法の書き方

### 連絡手段は2つ以上用意する

求職者によって好む連絡手段は異なります。電話だけ、Webフォームだけではなく、最低2つの手段を用意してください。

**推奨の書き方**
```
■ 応募方法（お好きな方法でご連絡ください）

- 電話：000-0000-0000（担当：○○）
  ※「求人を見た」とお伝えください
  ※受付時間：平日8:00〜17:00

- Web：https://xxxx（24時間受付・入力は1分で完了します）

- LINE：@xxxx（友だち追加して「求人について」と送信してください）
```

**連絡手段ごとの特徴**

| 手段 | メリット | 注意点 |
|------|--------|--------|
| 電話 | 即時対応できる。求職者の温度が高いうちに接点を持てる | 受付時間を明記する。出られない時間帯のフォロー体制も書く |
| Webフォーム | 24時間受付。求職者が自分のペースで入力できる | 入力項目を最小限にする。確認メールが届くことを明記する |
| LINE | 心理的ハードルが低い。気軽に質問できる | 公式アカウントの設定が必要。返信速度を意識する |
| メール | 時間を選ばず送れる | 迷惑メールに入る可能性がある。受信確認の返信を早くする |

### 電話番号は受付時間とセットで書く

建設業では、社長や現場責任者の携帯番号が応募先になることがあります。その場合でも、受付時間を明記してください。求職者は「何時にかけていいか分からない」と、結局かけずに終わることが多いです。

```
■ 良い例
電話：090-0000-0000（担当：山田）
※受付時間：平日8:00〜17:00
※作業中は出られないことがあります。折り返しますので留守番電話にお名前をお願いします

■ 避けたい例
電話：090-0000-0000（いつでもどうぞ!）
→ 「いつでも」と書かれると、逆にかけづらくなる人もいます
```

### Webフォームの入力項目は最小限にする

応募フォームの入力項目が多いと、途中で離脱されます。最低限必要な項目は4つです。

1. **名前**
2. **電話番号**（またはメールアドレス）
3. **希望職種**（複数募集の場合）
4. **ひとこと**（任意。「質問・相談があれば」程度）

住所・学歴・職務経歴は、面接時に聞けば十分です。応募段階で求める情報は少ないほど、送信完了率が上がります。

---

## 面接のハードルを下げる

### 面接回数を書く

「面接は1回」と書くだけで、応募のハードルは大きく下がります。2回・3回の面接は、中小企業の建設業採用では求職者の負担が大きく、途中辞退の原因になります。

### 履歴書のタイミングを書く

「履歴書は面接当日にお持ちください」と書くと、応募のハードルが下がります。応募時に履歴書を求めると「写真を撮らなきゃ」「手書きで書かなきゃ」と考えるだけで、応募を後回しにされます。

```
■ 推奨の書き方
面接は1回。履歴書は面接当日にお持ちいただければ結構です。
私服でお越しいただけます。
```

### 職場見学を提案する

「まず見学だけでも」という選択肢があると、応募のハードルが下がります。建設業の現場を見たことがない求職者にとって、見学は不安を解消する最も効果的な手段です。

```
■ 書き方の例
現場の見学も受け付けています。
「話だけ聞いてみたい」「現場を見てから決めたい」でも構いません。
```

## テンプレートへの活用方法

本書のテンプレート（第3部）は、すべて以下の構成で応募方法欄を書いています。

```
[CTAの一文：安心材料付きの行動喚起]

- 電話：【要記入】（担当：【要記入】）※「求人を見た」とお伝えください
- Web：【要記入】（24時間受付）
- LINE：【要記入】（公式アカウントがあれば）

[面接のハードルを下げる一文]
```

自社の求人に使う際は、以下を確認してください。

1. **電話番号と担当者名を入れたか**
2. **受付時間を明記したか**
3. **連絡手段を2つ以上用意したか**
4. **「まず話だけ」「見学だけ」の選択肢を入れたか**
5. **面接回数と履歴書のタイミングを書いたか**

原稿を全部読んでもらった後の「最後の一押し」を雑に書くと、それまでの努力が無駄になります。応募方法こそ、丁寧に書いてください。
