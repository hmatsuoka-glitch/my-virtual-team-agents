# 第4章　給与・待遇の見せ方（数字と条件はセット）

---

## 求職者が最初に見るのは「数字」

求人票を開いた求職者が真っ先に確認するのは、給与と休日の数字です。仕事内容よりも先に「月給いくらか」「休みは何日か」を見て、条件が合わなければその時点で離脱します。

だからこそ、数字の書き方で応募率が変わります。

ただし「数字を大きく見せれば応募が来る」という話ではありません。盛った数字で応募を集めても、面接や入社後に「話が違う」となれば、早期離職や口コミでの悪評につながります。

この章でお伝えするのは、**数字を正直に、しかし魅力的に見せる方法** です。

---

## 月給の書き方

### 基本ルール：レンジで書き、到達条件を添える

| 書き方 | 求職者の受け取り方 |
|--------|---------------|
| 月給25万円〜 | 「〜」の上限が分からず不安。25万円固定だと思われやすい |
| 月給25万〜35万円 | レンジが分かるので安心。ただし「35万円は何年目?」と疑問が残る |
| 月給25万〜35万円（経験・資格を考慮して決定） | 判断基準が分かる |

**推奨の書き方**
```
月給 25万〜35万円
※経験・資格・前職給与を考慮して決定します
※未経験の方：月給25万円〜（入社1年目の目安）
```

ポイントは3つです。

1. **レンジの下限と上限の両方を書く** — 下限だけだと「最低額しかもらえない」と思われる
2. **何で変わるかを書く** — 「経験」「資格」「前職給与」など判断基準を明示する
3. **未経験の方の目安を分けて書く** — 経験者と未経験者が同じレンジだと、未経験者は上限に目が行き期待値がズレる

### 月給に含まれるものを明示する

建設業では「月給30万円」と書いてあっても、中身が基本給なのか、固定残業代込みなのか、各種手当込みなのかで、実質の待遇がまったく違います。

```
■ 書くべき内訳
月給 28万〜35万円
（内訳：基本給 24万〜30万円 ＋ 固定残業手当 4万〜5万円※月20時間分）
※固定残業時間を超えた分は別途全額支給します
```

固定残業代（みなし残業代）を含む場合は、金額と時間数の両方を書くことが法律で義務づけられています。書かないと求人票の差し戻し対象になります。

### 日給制の場合

日給制の場合は、日給と月収の目安をセットで書いてください。日給だけだと、求職者が月収を計算する手間がかかり、離脱の原因になります。

```
日給 1.3万〜1.8万円
※月収例：日給1.3万円 × 月22日勤務 = 月収約28.6万円
```

「月22日」などの勤務日数は実態に合った数字を使ってください。勤務日数を多く見積もって月収を大きく見せると、入社後のギャップになります。

## 賞与の書き方

### 「賞与あり」だけでは弱い

「賞与あり」は求職者にとって判断材料になりません。回数と実績を書くことで初めて信頼される情報になります。

| 弱い書き方 | 信頼される書き方 |
|----------|--------------|
| 賞与あり | 賞与 年2回（前年度実績：計3ヶ月分） |
| 業績による | 賞与 年2回（前年度実績：計2.5ヶ月分）※業績により変動あり |

**注意点**: 実績の数字は直近のものを使い、古い数字を都合よく引っ張らないでください。数字が古いと、入社後に「あの年は良かっただけ」となります。

賞与の実績がまだない場合や変動が大きい場合は、正直に書いてください。
```
賞与 年2回（業績に応じて支給）※創業間もないため実績なし
```

## 手当の書き方

### 「各種手当あり」は情報ゼロ

手当は種類と金額を具体的に書いてください。「各種手当あり」では何がいくらもらえるか分かりません。

**書き方の例**
```
- 通勤手当（月3万円まで実費支給）
- 資格手当（1級施工管理技士：月2万円、2級：月1万円）
- 家族手当（配偶者：月1万円、子1人あたり：月5,000円）
- 現場手当（遠方現場の場合：日額2,000円）
- 工具手当（自前の道具を使用する場合：月5,000円）
```

手当が少ない場合でも、ある手当は書いてください。何も書かないと「手当がない会社」だと思われます。通勤手当と資格手当の2つだけでも、書けば「ちゃんとした会社」という印象になります。

---

## 年間休日の書き方

### 日数と内訳をセットで書く

「年間休日105日」だけでは、どの曜日が休みで、祝日はどうなるのかが分かりません。

**推奨の書き方**
```
年間休日 110日
（日曜・祝日休み、土曜は会社カレンダーによる ※月1〜2回の土曜出勤あり）
※GW・夏季・年末年始に長期休暇あり
```

建設業では「土曜は現場次第」というケースが多いですが、そのまま正直に書いてください。「完全週休2日」と書いて実態が違うほうが、入社後のトラブルになります。

### 年間休日の数え方に注意

年間休日に有給休暇を含めて数字を大きく見せるケースがありますが、有給休暇は法定で別途付与されるものです。年間休日と有給は分けて書いてください。

```
■ 正しい書き方
年間休日 105日（日曜・祝日・会社カレンダーによる土曜）
有給休暇あり（入社6ヶ月後に10日付与）

■ やってはいけない書き方
年間休日 115日（有給含む）
```

## 社会保険の書き方

建設業では「社会保険完備」が当たり前ではない会社もあるため、加入していることを明記するだけで差別化になります。

```
社会保険完備（健康保険・厚生年金・雇用保険・労災保険）
```

「社会保険完備」の一言でも問題ありませんが、4つの保険名を書くことで「本当に全部入っている」という安心感が伝わります。建設国保の場合は、その旨を明記してください。

## 福利厚生のチェックリスト

自社に該当する項目を確認して、求人票に記載してください。「あって当然」と思っている制度も、書かなければ求職者には伝わりません。

- [ ] 社会保険完備
- [ ] 退職金制度（建退共・中退共など）
- [ ] 資格取得支援制度（費用負担の範囲）
- [ ] 資格手当（種類別の月額）
- [ ] 通勤手当（上限額）
- [ ] 家族手当
- [ ] 住宅手当・社宅・寮
- [ ] 作業着・安全靴・ヘルメットの貸与
- [ ] 工具手当（自前の道具を使う場合）
- [ ] 車通勤可・駐車場
- [ ] 有給休暇
- [ ] 長期休暇（GW・夏季・年末年始の日数）
- [ ] 健康診断（年1回）
- [ ] 慶弔見舞金

## 数字を書くときの3つの鉄則

### 1. 盛らない

実態より良い数字を書いて応募を集めても、面接で事実が分かれば辞退されます。入社しても「騙された」と早期離職につながります。控えめに書いて入社後に「思ったより良い」と感じてもらうほうが、長期的に得です。

### 2. 曖昧にしない

「各種手当あり」「休日は会社カレンダーによる」「給与は経験による」――これらはすべて情報ゼロです。具体的な数字と条件を書けば書くほど、求職者の信頼が高まります。

### 3. 条件をセットにする

数字だけを書くと誤解が生まれます。「月給35万円」だけ見て応募した人が、面接で「それは10年経験者の場合です」と言われれば不信感が残ります。数字には常に「誰が」「どの条件で」その金額になるのかを添えてください。

## テンプレートへの活用方法

本書のテンプレート（第3部）では、給与・待遇欄のすべての数字に【要記入】マークをつけています。記入する際は、この章のルールに沿って以下を確認してください。

1. **月給のレンジは下限と上限の両方を書いたか**
2. **固定残業代がある場合、金額と時間を明記したか**
3. **未経験者と経験者の目安を分けて書いたか**
4. **賞与の回数と前年度実績を書いたか**
5. **手当は種類と金額を具体的に書いたか**
6. **年間休日の日数と曜日の内訳を書いたか**
7. **有給休暇を年間休日に含めていないか**

数字の見せ方で応募数は変わります。しかし、盛って集めた応募からは定着しません。正直な数字を、分かりやすく、信頼される形で書く。それが結果的に「応募が来て、辞めない採用」につながります。
