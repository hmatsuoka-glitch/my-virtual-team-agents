# 第5章　「未経験歓迎」を嘘にしない書き方

---

## 「未経験歓迎」と書くだけでは足りない

求人票に「未経験歓迎」と書くのは簡単です。しかし、それだけで未経験者が安心して応募できるかというと、そうではありません。

未経験の求職者が本当に知りたいのは、こういうことです。

- 「入社初日から一人で現場に出されないか」
- 「教えてくれる人は本当にいるのか」
- 「ついていけなくて辞める人は多くないか」

「未経験歓迎」の4文字は、これらの不安に何一つ答えていません。答えるためには、**教育体制を具体的に書く**必要があります。

---

## 教育体制の書き方：3つの要素

未経験者への教育体制を伝えるには、以下の3つを書いてください。

### 1. 「誰が」教えるのか

> 「先輩がマンツーマンで教えます」

これだけでは弱いです。もう一段階具体的にしてください。

**弱い書き方**
```
先輩社員がOJTで指導します。
```

**信頼される書き方**
```
入社後3ヶ月間は、経験○年の先輩が専属で隣につきます。
最初の1週間は現場に出ず、事務所で道具の名前・安全ルール・
図面の読み方を研修します。
```

「専属」「○年の先輩」「最初の1週間は事務所で」という具体性が、信頼感を生みます。

### 2. 「何を」「いつまでに」覚えるのか

求職者が最も怖いのは「ゴールが見えない」ことです。ステップ表を書くだけで、「自分にもできそうだ」という安心感に変わります。

**書き方の例**
```
■ 入社後のステップ
- 1〜3ヶ月：道具の名前と使い方・現場の安全ルールを覚えます
- 4〜6ヶ月：簡単な作業を任されるようになります
- 1年〜：一通りの作業を先輩と一緒にこなせるようになります
- 2〜3年：資格取得を目指します（費用は会社負担）
```

本書のテンプレートにはすべてこのステップ表が入っています。自社の実態に合わせて時期と内容を調整してください。

### 3. 「実際に未経験で入社した人はいるのか」

いくら「未経験歓迎」と書いても、「本当に未経験で入った人はいるのか?」という疑問が残ります。これを打ち消す最も効果的な方法は、**実績を数字で書く**ことです。

**書き方の例**
```
当社の作業員○名のうち、○名が未経験から入社しています。
前職はコンビニ店員、工場作業員、飲食スタッフなど、
建設と無関係の仕事をしていた人がほとんどです。
```

数字が書けない場合でも、「前職」の具体例を出すだけで信頼性が上がります。「異業種からの転職者が活躍しています」よりも、「前職が配送ドライバーだったスタッフが、今は現場のリーダーを務めています」のほうが響きます。

## 「未経験歓迎」でやってはいけないこと

### NG1：未経験歓迎と書きながら、応募条件に経験を求める

```
■ 矛盾の例（やってはいけない）
タイトル：未経験歓迎!
応募条件：実務経験3年以上の方

■ 正しい書き方
タイトル：未経験歓迎
応募条件：未経験歓迎（建設業の知識がなくても大丈夫です）
         ※経験者の方は技術に応じて優遇します
```

未経験と経験者の両方を募集したい場合は、「未経験歓迎」の原稿と「経験者優遇」の原稿を分けて出すのが理想です。1つの原稿でまとめる場合は、給与欄で「未経験スタートの場合：月給○万円〜」「経験者の場合：前職給与を考慮」と分けて書いてください。

### NG2：教育体制がないのに「未経験歓迎」と書く

教育体制が整っていない段階で「未経験歓迎」と書いて採用すると、入社者が放置されて早期離職につながります。「歓迎」と書く以上、最低限の教育プラン（誰が・何を・いつまでに教えるか）を社内で決めてから求人を出してください。

教育体制が今はない場合は、正直に「経験者優遇」で出し、その分給与を高く設定するほうが、結果的にうまくいきます。

### NG3：「やる気があればOK」だけで終わる

```
■ 弱い書き方
やる気と体力があれば大丈夫!

■ 改善例
未経験歓迎（入社後に一から教えます）。
最初の3ヶ月は先輩が専属でつき、道具の名前から覚えていきます。
体を動かすのが好きな方に向いています。
```

「やる気」は求職者自身が判断するものです。会社側が書くべきは「やる気がある人に対して、何を用意しているか」です。

## 資格取得支援の書き方

建設業の未経験採用では、資格取得支援が大きな訴求ポイントになります。しかし「資格取得支援あり」だけでは何を支援してくれるのか分かりません。

**具体的に書くべき項目**
```
■ 資格取得支援制度
- 対象資格：○○技能士・玉掛け・足場の組立て等作業主任者
- 費用負担：受験費用・テキスト代・講習費を全額会社負担
- 取得後：資格手当を毎月支給（○○技能士：月○円）
- 実績：過去○年で○名が資格を取得しています
```

「全額会社負担」「毎月支給」「過去○名が取得」――この3点を書くことで、「本気で支援してくれる会社だ」という印象になります。

---

## テンプレートへの活用方法

本書のテンプレートで「未経験歓迎」の職種（No.2, 3, 5, 6, 7, 8, 12, 14, 20）には、ステップ表と教育体制の記述が含まれています。自社の求人に使う際は、以下を確認してください。

1. **ステップ表の時期を自社の実態に合わせたか** — 「1〜3ヶ月で○○」は会社によって異なります
2. **教育担当者を具体的に書けるか** — 「先輩」ではなく「経験○年の先輩」「現場責任者の○○」など
3. **未経験入社の実績を数字で書けるか** — 「○名中○名が未経験入社」
4. **資格取得支援の具体内容を書いたか** — 対象資格・費用負担の範囲・取得後の手当

「未経験歓迎」は採用のチャンスを広げる強力な訴求です。しかし嘘になった瞬間に、早期離職と悪評という大きな代償を生みます。書けること・用意できることだけを書いてください。
