# 第3章　仕事内容は「1日の流れ」で書く

---

## なぜ「1日の流れ」が必要なのか

求人票の仕事内容欄に、こう書いていませんか。

> 「建設現場での施工管理業務全般」
> 「土木工事に関する作業」

これを読んだ求職者は、こう思います。「で、具体的に何をするの?」

特に未経験者にとっては「施工管理業務全般」という言葉から実際の仕事を想像することは不可能です。経験者であっても「全般」の中身は会社によって違うので、入社後の日常がイメージできません。イメージできない仕事には応募できない。これが「仕事内容を書いているのに応募が来ない」原因の一つです。

解決策はシンプルです。**朝から夕方まで、時間軸で書く。** これだけで、読む人が「自分がその現場で働いている姿」を思い浮かべられるようになります。

---

## 書き方の型

以下の型に沿って書くと、抜け漏れなく具体的な仕事内容になります。

```
■ ある1日の流れ
- ○:○○　[出社 or 集合 or 現場到着]・[最初にやること]
- ○:○○　朝礼・[安全確認・作業確認]
- ○:○○　[午前の主な作業内容]
- ○:○○　小休憩
- ○:○○　[午前の作業の続き]
- 12:00　昼休憩
- 13:00　[午後の主な作業内容]
- ○:○○　小休憩
- ○:○○　[午後の作業の続き]
- ○:○○　片付け・道具の手入れ・翌日の段取り
- ○:○○　[退社 or 現場を出発]
```

---

## 書くときの5つのポイント

### 1. 時間は実態どおりに書く

「8:00始業」と書いてあるのに実際は7:00集合だと、入社後に「話が違う」となります。直行直帰なのか、会社に集合してから移動するのか、移動時間はどれくらいか。ここを正直に書くことで、入社後のギャップを防げます。

**書き方の例**
- 会社集合の場合：「7:30　会社に集合 → 車で現場へ移動（片道30分圏内の現場が中心）」
- 直行直帰の場合：「8:00　現場に直行（自宅から現場への移動。現場は○○市内が中心）」

### 2. 作業名だけでなく「何をしているか」を1行で添える

「施工管理業務」だけでは伝わりません。「施工管理」が実際にやっていることを分解して書きます。

| 抽象的な書き方 | 具体的な書き方 |
|--------------|-------------|
| 施工管理業務 | 現場巡回・施工状況の確認・写真撮影 |
| 土木作業 | 掘削・運搬・土ならし・コンクリート打設の補助 |
| 塗装工事 | 養生 → 下地処理 → 下塗り → 中塗り → 上塗り |
| 電気工事 | 配管の敷設 → 電線の通線 → 器具の取付け |

ポイントは「動詞で書く」ことです。「○○業務」という名詞ではなく「○○する」「○○を確認する」と書くと、読む人が動作を想像できます。

### 3. 未経験者向けには「最初にやること」を分けて書く

未経験の方が最も知りたいのは「入社初日から一人で現場に放り出されないか」という不安の答えです。「未経験歓迎」と書くだけでは不十分で、入社後に何から教わるのかを具体的に書く必要があります。

**書き方の例**
```
■ 未経験の方の入社後
最初は○○の運搬や、先輩が○○した後の補助からスタートします。

- 1〜3ヶ月：○○を覚えます
- 4〜6ヶ月：○○を任されるようになります
- 1年〜：一通りの○○ができるようになります
```

この「ステップ表」があるだけで、「自分にもできそうだ」と思える求職者が増えます。

### 4. 休憩を書く

「休憩なんて当たり前だから書かなくていい」と思うかもしれませんが、求職者は「本当に休憩があるのか」を気にしています。特に建設業は「休憩なしで働かされる」というイメージを持っている人もいます。午前と午後の小休憩、昼休憩の時間を明記するだけで、「まともな現場だ」という安心感につながります。

### 5. 退社時間を書く

「17:30退社」と書くことに抵抗がある会社もあるかもしれません。しかし書かなければ「何時に帰れるか分からない」と思われ、応募のハードルが上がります。

残業がある場合は、正直に書いてください。

- 「17:30　退社（月の残業は平均○時間程度）」
- 「17:30　退社 ※繁忙期（○月〜○月）は1〜2時間の残業があります」

「残業ゼロ」と書いて実態と違うよりも、「月平均20時間」と正直に書いたほうが、入社後の定着率は上がります。

## やりがちなNG例と改善例

### NG例1：箇条書きなしの長文

> 出社後、朝礼に参加し、その後現場に移動して作業を行います。午前中は主に施工管理業務を行い、午後は書類作成や打ち合わせなどを行います。

**何がダメか**: 時間が分からない。作業の具体性がない。目が滑る。

**改善例**: 本テンプレートの「1日の流れ」形式に書き換える。

### NG例2：良いことだけ書く

> 定時退社が基本です。残業はほとんどありません。

**何がダメか**: 「ほとんど」が曖昧。入社後に残業があると「騙された」と感じる。

**改善例**: 「17:30退社。月の残業は平均15時間程度（繁忙期は月25時間になることがあります）」

### NG例3：社内用語・略語を使う

> 「KYK後、重機回送して床付け、その後ネコで残土搬出」

**何がダメか**: 未経験者には何一つ伝わらない。

**改善例**: 「朝礼・安全確認（KY活動）の後、重機を使って地面を掘り、一輪車で土を運び出します」。どうしても専門用語を使う場合は、括弧で補足をつけてください。

## テンプレートへの活用方法

本書のテンプレート（第3部）はすべて「1日の流れ」形式で書かれています。自社の求人に使う際は、以下の手順で調整してください。

1. **時間を自社の実態に合わせる** — 始業・終業・休憩時間を実際のスケジュールに書き換える
2. **作業内容を自社の現場に合わせる** — テンプレートの作業名を、自社で実際にやっている作業に差し替える
3. **移動方法を書く** — 会社集合か直行直帰か。移動時間の目安も添える
4. **【要記入】欄を埋める** — 現場の種類、担当件数など自社固有の情報を記入する

「こんな細かいことまで書くの?」と感じるかもしれませんが、求職者にとっては、この細かさが「信頼できる会社だ」という判断材料になります。
