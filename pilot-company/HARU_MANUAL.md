# HARU操作マニュアル — X・noteの使い方

> AI社員はドラフト作成まで。**公開ボタンを押すのはHARUだけ**（ガードレール）。
> このマニュアルは日々の操作に迷ったときに見返す用。

## 導線の全体像

```
X（集客の入口）─── 毎日の発信で見込み客を集める
   │  プロフィールのリンクから誘導
   ▼
note（販売の出口）─ 無料記事で信頼構築 → 有料記事（商品）で売上
```

## X — 自動投稿（APIキー設定後は作業ゼロ）

### 自動投稿のセットアップ（1回だけ・約20分）

X投稿は公式APIで完全自動化する（投稿単価 $0.01 の従量課金。1日2投稿で月100円未満）。

1. https://developer.x.com にXアカウントでログインし、開発者登録（従量課金 Pay-Per-Use。最低 $5 のクレジットチャージ）
2. アプリを作成し、**User authentication settings** で権限を「Read and write」に設定
3. 「Keys and tokens」から4つのキーを発行:
   API Key / API Key Secret / Access Token / Access Token Secret
4. claude.ai の Claude Code **環境設定 → 環境変数** に以下の名前で登録:
   `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_TOKEN_SECRET`
5. 以降、朝会（9:00台）と昼会（13:00台）が1本ずつ自動投稿する（`scripts/post_to_x.py` 経由・上限2本/日・全件 `logs/x_posts.csv` に記録）

### キー設定前（または障害時）の手動フロー
1. 17:30の終業通知 → `tasks/backlog.md` の `[承認待ち]` を確認
2. 投稿本文は `drafts/` 配下のファイルにある
3. OK → コピーしてXに投稿 → backlog の行を `[公開済み]` に変更（面倒なら「→OK 投稿済み」と追記でも可。翌セッションが整理する）
4. NG → その行に `→修正: <一言>` と書く（翌朝会でAIが修正）

### 自動投稿の緊急停止
- 環境変数を削除する（次のセッションから承認待ち運用に自動で戻る）
- 問題のある投稿を見つけたらX上で削除し、backlog に一言書く（AIが learnings.md に原因と再発防止を記録する）

### 初回セットアップ（AIのドラフト承認後）
- プロフィール編集: AI作成のプロフィール文を貼る。ウェブサイト欄に **noteのURL**
- 自己紹介投稿をポスト → 「…」メニュー → **プロフィールに固定**

### 週次（金曜の朝までに）
- 今週の投稿インプレッション合計を確認（各ポストの「アクティビティ」）
- backlog に1行貼る（例: `今週のXインプレッション合計: 12,400`）
  → 金曜16:00の週次会議がこの実データで分析する。Phase 2 で自動取得に移行予定

### 人間がやること（AIに任せない）
- リプライ・DMへの返信（信頼の源泉。返信の文案作成をAIに頼むのはOK）

## note — 週2〜3回・各10分（公開クリックは人間）

> noteには公式の投稿APIが存在しない（2026年7月時点・公開予定も未定）。
> 非公式APIやブラウザ自動化での完全自動投稿は技術的には可能だが、規約上グレーで
> **販売チャネルのアカウント凍結リスク**があるため採用しない。
> 記事本文はAIが完成品まで作るので、人間の作業は「貼り付けて公開ボタン」のみ（週2〜3回・各10分）。

### 無料記事（集客用・週2本ペース）
1. note右上「投稿」→「テキスト」
2. `drafts/` のドラフトからタイトル・本文を貼り付け
3. 公開設定「無料」のまま、ハッシュタグ（#採用 #建設業 など）を付けて公開

### 有料記事（商品。最初はP1の1本）
1. 同じ手順で本文貼り付け（テンプレート集本体がそのまま記事になる）
2. 公開設定で「**有料**」→ 価格入力（P1: ¥3,000）
3. **有料ライン設定が最重要**: AIのドラフト内の「━━ ここから有料 ━━」マーカーの位置に有料ラインを合わせる
   - 定石: 冒頭〜目次・サンプル1点まで無料公開、本体は有料側
4. 公開後、記事URLを **Xのプロフィールと固定ポストに貼る**

### 売上が発生したら
- note「ダッシュボード → 売上管理」で確認
- `ledger/sales.csv` に1行追記:
  `2026-07-15,P1,note,1,3000,3000,450,2550,初売上`
  （date, product, channel, qty, unit_price, gross, fee, net, note の順。feeは概算15%でOK、finance が精査する）
- CSVが面倒なら backlog に「7/15にP1が1件売れた」と書くだけでも可（終業セッションが転記）

### 週次（金曜の朝までに）
- ダッシュボードの「全体ビュー数」を backlog に1行貼る（例: `今週のnoteビュー: 320`）
